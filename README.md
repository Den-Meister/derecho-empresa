# Derecho y Empresa — Guía de Estudio (FEN-UDD)

Guía de estudio interactiva para el curso **Derecho y Empresa** (Ingeniería Comercial, Facultad de Economía y Negocios, Universidad del Desarrollo).

Página única, tema oscuro, pensada para estudiar y repasar de cara a las evaluaciones. Contenido basado en el material del curso.

## Contenido actual

**Unidad I — Aspectos Legales Fundamentales**
- Para qué sirve el derecho a quien decide en una empresa (ejes de riesgo y valor)
- Estado de Derecho
- Kelsen y la Pirámide de Kelsen (jerarquía normativa)
- La Constitución y el Art. 19 N°21 CPR
- Tipos de norma y sus quórums (tratados, LOC, LQC, ordinarias, DFL, DL, reglamentos, circulares, ordenanzas, sentencias y contratos)
- El diagnóstico rápido de una norma (4 preguntas)
- Responsabilidad civil contractual vs. extracontractual

Se irá ampliando con las próximas unidades del curso.

## Cómo verla

Abre `index.html` en cualquier navegador, o visita la versión publicada con GitHub Pages.

## Publicar con GitHub Pages

1. Sube este repositorio a GitHub (público).
2. Ve a **Settings → Pages**.
3. En *Branch*, elige `main` y carpeta `/ (root)`. Guarda.
4. En ~1 minuto la página estará disponible en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
